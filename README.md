## How to Run & Preview
- **Option 1 (Instant):** Double-click `index.html` to open directly in any web browser.
- **Option 2 (Local Server):** Double-click `start_server.bat` or run `python -m http.server 8080` in this directory and open `http://localhost:8080`.
